# hinteros-catalog

The curated App Store catalog for [HinterOS](https://justsomeshed.com/JSwartz/HinterOS/hinteros):
one entry per app that a HinterOS box can install from Settings or the first-boot wizard.

The catalog format and how boxes fetch it are being designed (M8). Unfree apps such as Plex and
Steam are listed here but never redistributed: their packages are fetched and built on the box.
